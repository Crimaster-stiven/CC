# 🍅 番茄钟 - Pomodoro Timer

一个基于 Electron 的桌面番茄钟应用，帮助提高专注力。

## 功能

- **番茄计时** — 25 分钟专注 + 5 分钟短休息 / 15 分钟长休息
- **自定义时长** — 专注、短休、长休时间均可自由调整
- **任务管理** — 添加任务列表，选择当前任务
- **圆环进度** — 可视化倒计时进度
- **系统托盘** — 隐藏到托盘后台运行
- **桌面通知** — 番茄完成或休息结束时弹出提醒
- **历史记录** — 按日期统计番茄完成数量和时长
- **窗口置顶** — 可切换窗口始终显示在最前面
- **键盘快捷键** — 空格开始/暂停，R 重置，1/2/3 切换模式

## 使用

确保已安装 [Node.js](https://nodejs.org/)（>= 16）。

```bash
# 安装依赖
npm install

# 启动应用
npm start

# 开发模式（打开 DevTools）
npm run dev
```

## 快捷键

| 按键 | 功能 |
|------|------|
| `Space` | 开始 / 暂停 |
| `R` | 重置计时 |
| `1` | 专注模式 |
| `2` | 短休息 |
| `3` | 长休息 |
| `Esc` | 关闭历史面板 |

## 技术栈

- [Electron](https://www.electronjs.org/)
- Vanilla JS（无框架依赖）
- LocalStorage 持久化
